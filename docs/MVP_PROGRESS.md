# MVP 交付记录

日期：2026-09-07。

- 复用 S05 知识库：4 份已审核 PDF、1561 个质量为 OK 的文档片段。
- 本地 embedding：`qwen3-embedding:0.6b`，1024 维，Chroma cosine 索引。
- 检索：原问题 dense + BM25 中英术语扩展 + RRF；产品范围过滤、重复页眉过滤，最多 12 块/11000 字符。
- 输出：Pydantic 禁止额外字段；模型只选择 allowlist 内 chunk ID；程序绑定原文、页码、版本、URL 和构建 ID；第二次模型检查证据是否支持完整问题。
- 参数：支持显式 VIN/VOUT/持续电流、mA 换算、纠正、未知浪涌、禁止强制风冷、型号和指代歧义；每个值保留原句切片。
- 界面：Streamlit 页面、CLI、双击启动脚本；全部使用同一服务。
