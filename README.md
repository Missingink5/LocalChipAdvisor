# LocalChipAdvisor

本地封闭运行的 MPS Buck 芯片辅助选型原型。

首版目标：针对 20–30 个 MPS 非隔离、集成功率 MOSFET 的同步降压转换器，完成自然语言需求澄清、结构化硬约束过滤、Top 3 排序、近似/待核实候选展示，以及与官方资料绑定的可追溯证据。

## 当前状态

- 已完成需求边界与验收标准定义。
- 正在核验本地模型与 Python 依赖。
- 尚未导入产品资料，当前不得产生正式芯片推荐。

## 安全边界

- 安装与资料准备阶段允许联网。
- 运行阶段只监听 `127.0.0.1`，不调用云端 API。
- 原始资料、索引、日志和回答均保留在本机。
- 默认不持久化原始问题或完整回答。
- 所有导入文档均按不可信内容处理，不能覆盖系统规则或触发工具。
- 本系统仅用于辅助选型；进入原理图、BOM 或样机前必须由工程师复核。

详细约定见 [docs/requirements.md](docs/requirements.md)。
